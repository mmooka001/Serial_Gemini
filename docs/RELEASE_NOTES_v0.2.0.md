# Gemini Serial v0.2.0

## 界面与交互

- 顶栏与左侧导航共用磨砂背景，工作区按模块划分，连接、指令、码表、设置共用面板宽度。
- 保留原有液态玻璃导航选框与配色，支持长按约 0.3 秒后滑动，松手切换至最近的选项，并带轻微回弹。
- 新增深色、浅色、跟随系统，以及四种配色风格、预设强调色、色谱和 HEX 自定义颜色。
- 重新安排单条指令布局，突出指令正文；支持清晰拖选、长按排序、TXT/HEX 按钮及液态玻璃右键菜单。
- 终端消息可拖选复制，保留原始空白并按纯文本显示；菜单滚动时关闭，主题按钮和三个点支持再次点击收起。
- 调整窗口最大化、置顶还原、拖动还原、面板分界与边距，修复侧栏空白区域的滚轮响应。

## 串口与发送

- HEX 模式不自动附加行尾；检测到普通文本时，按所选编码转换为 HEX，并保留发送模式。
- 明确 BCC 为逐字节异或校验，保留 Sum8 和 CRC16 Modbus。
- 发送框循环与指令循环使用独立的开关和间隔，并支持直接编辑间隔。
- 保留接收解码状态，修复中文等多字节字符跨接收块时的乱码。
- 大消息分块排队发送，并在整条消息写入完成后记录 TX；修正停止位枚举映射和空指令处理。

## 下载与运行

- Windows 10 / Windows 11 x64，基于 Qt 6.11 和 MinGW。
- 下载 `Gemini-Serial-v0.2.0-win64.zip`，完整解压后运行 `GeminiSerial.exe`，无需安装 Qt。
- 保持 EXE 与附带 DLL、qml、platforms 等目录在一起。
- 使用附带的 `.sha256` 文件核对下载完整性。
- 指令和设置沿用系统应用数据目录；发布包不附带个人指令、日志或测试文件。
