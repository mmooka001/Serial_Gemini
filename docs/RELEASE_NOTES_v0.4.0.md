# Gemini Serial v0.4.0

## 多文件指令库

- 指令改为保存在可执行文件旁的 `Commands` 目录，每个 JSON 是一份独立指令库。
- 指令面板新增文件选择器，以及新建、刷新、打开目录按钮，并记住上次选择的文件。
- 导入先校验 JSON 与指令结构，再复制到目录并打开；同名文件自动增加序号，直接导入目录内已有文件时只打开该文件。
- 编辑自动写回当前文件；切换文件前提交正在编辑的文字，停止指令循环并清空勾选，避免继续发送另一份文件中的指令。
- 刷新重新扫描目录并读取文件，便于在文件管理器或编辑器中管理 JSON。
- 保存使用临时文件原子替换，并检查外部修改；另一窗口同时保存、文件被移走或无法写入时提示原因，保留内存中的编辑。
- 未保存内容以文件名后的 `*` 标记；放弃编辑刷新或关闭程序前会确认，可先导出备份。

## 发送按钮

- 指令面板和发送框的“循环”统一改为“循环发送”，使用与“发送”一致的实心强调色。
- 循环运行时显示“停止发送”，保持清晰的停止状态。
- 单条指令的小飞机发送图标与右键菜单的发送项使用主题强调色，随配色切换。

## 升级与数据位置

- **升级或移动软件时，请一并保留原来的 `Commands` 文件夹。** 发布 ZIP 只包含空目录，不携带个人指令。
- 首次在该位置运行，会将旧版系统应用数据目录中的 `commands.json` 复制为 `Commands/旧版指令.json`，原文件保留。没有旧指令时创建空的 `默认指令.json`。
- 界面偏好和串口配置继续使用原来的系统设置位置。
- 请将软件解压到可写入的目录，并保持 EXE、DLL、qml、platforms 等目录在一起。

## 下载与运行

- Windows 10 / Windows 11 x64。
- 下载 `Gemini-Serial-v0.4.0-win64.zip`，完整解压后运行 `GeminiSerial.exe`，无需安装 Qt。
- 附件包含 ZIP、SHA-256 校验文件和上述两张历史布局参考图。
- 发布包不包含源码、测试、日志、开发环境或个人指令数据。
