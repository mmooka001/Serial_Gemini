# Gemini Serial v0.3.0

## 指令整理与滚动

- 文件夹标题支持长按上下排序；开始拖动时先收起所有分组中的指令，只留下文件夹标题。
- 放下或取消拖动后，恢复各分组原来的展开状态，保留勾选归属，并定位到移动后的文件夹。
- 收起前保存编辑草稿，避免正在编辑的内容随临时界面收起而丢失。
- 编辑指令或重命名文件夹时局部更新，避免重建整张列表导致位置跳回顶部。
- 数据终端和指令列表右侧新增统一的细滚动条，内容溢出时显示并可拖动。

## HEX 输入规则调整

HEX 模式中，只转换英文双引号内的文字，并使用设置中选择的编码。可以混合字节与文字：

```text
01 "AT" 0D  →  01 41 54 0D
```

引号本身不发送，支持 `\n`、`\r`、`\t`、`\"`、`\\` 转义。未加引号的非 HEX 内容会提示错误并阻止发送，避免误判。

旧的 HEX 指令若直接填入普通文本，请补上双引号，或把该条指令切换为 TXT 模式。TXT 输入规则不变。

## 偏好、窗口与时间戳

- 保存接收/发送 HEX 模式、时间戳、滚动跟随、置顶、校验方式、循环间隔、面板与窗口布局等偏好。
- 记住上次选择的串口参数；不自动建立连接或启动循环发送。
- 统一窗口状态管理，修正最大化/全屏后最小化，再恢复成屏幕大小普通窗口的问题；最小化期间保留原生边框状态。
- 时间戳在 C++ 收发回调中记录，终端与导出共用同一时刻，显示到毫秒。接收时间表示软件收到这一批数据的时刻，受系统调度和驱动缓冲影响，不是逐字节硬件时间戳。

## 下载与运行

- Windows 10 / Windows 11 x64。
- 下载 `Gemini-Serial-v0.3.0-win64.zip`，完整解压后运行 `GeminiSerial.exe`，无需安装 Qt。
- 保持 EXE 与附带 DLL、qml、platforms 等目录在一起。
- 附件包含 ZIP、SHA-256 校验文件和此前提供的两张界面布局截图。
- 发布包不包含个人指令、日志、测试文件或开发环境。
