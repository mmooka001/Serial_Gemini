# Gemini Serial 宣传文案

## GitHub 仓库简介

基于 Qt 6、QML 与 C++17 开发的现代化 Windows 串口调试助手，支持 HEX/TXT 收发、CRC16/BCC/SUM8 校验、指令预设、循环发送、记录导出、明暗主题与响应式布局。

## 中文短介绍

Gemini Serial 是一款面向嵌入式开发和硬件联调的开源串口调试工具。它将串口配置、数据收发、校验计算、指令管理和通信记录整合在一个现代化界面中，并提供明暗主题与自适应布局。项目使用 Qt 6、QML 和 C++17 开发，源码结构精简，适合直接使用、学习或二次开发。

## 中文发布文案

我开源了一款 Qt 6 串口调试助手：**Gemini Serial**。

它面向嵌入式开发、单片机调试和串口协议测试，支持：

- TXT / HEX 数据收发
- CRC16 Modbus、BCC、SUM8 校验
- 常用指令分组、搜索、导入与导出
- 多指令循环发送和自动发送
- 通信记录与 RX/TX 字节统计
- 明暗主题、窗口置顶和响应式布局

项目使用 Qt 6 + QML + C++17 开发，已经整理了完整源码、构建说明和运行截图，并采用 MIT License 开源。

## English Introduction

Gemini Serial is an open-source serial port assistant built with Qt 6, QML, and C++17. It is designed for embedded development, hardware debugging, and serial protocol testing. Features include TXT/HEX communication, CRC16 Modbus/BCC/SUM8 checksums, command presets, loop sending, record export, traffic statistics, dark and light themes, and a responsive desktop interface.

Repository: https://github.com/mmooka001/Serial_Gemini
