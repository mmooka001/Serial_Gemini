# Gemini Serial v0.6.0

- 接收支持按时间窗口或固定字节数分包，时间最低为 1 ms。状态栏显示当前行尾、编码和所选文字的字节数。清除终端会同时重置收发统计。
- Enter 发送，Shift+Enter 换行。发送框和指令区的循环间隔可分别设为 1–3,600,000 ms。写入停滞时停止循环并提示，超时会断开串口。实际发送速度取决于定时器、波特率和流控。
- 左侧「比对」支持直接输入或粘贴 A、B 文本。右侧实时保留 A 原文，标红被删改的内容，并在下一行标绿 B 的差异。三个文本区均可滚动，右侧刻度显示差异位置。
- 长消息默认显示短预览，可分页查看或复制全文。终端分批刷新记录，大段发送输入延迟更新预览，降低文本排版和转换开销。
- 界面字号按原有层级缩放，数据字号可独立调整。两项字号支持输入和箭头调节。顶栏、软件图标和发送提示对齐已调整。
- 优化最大化、全屏与窗口还原的状态切换。原生磨砂不可用时使用实色背景，显卡渲染异常时可用 `GeminiSerial.exe --software-rendering` 启动。

## 下载与升级

下载 `Gemini-Serial-v0.6.0-win64.zip`，完整解压后运行 `GeminiSerial.exe`。目标平台为 Windows 10 1809 及以上、Windows 11 x64。

升级时将原有 `Commands` 文件夹复制到新版 EXE 旁边。建议将新版解压到可写目录，并保留附带的 Qt DLL、`qml` 和 `platforms` 目录。
